Apps and small fixes for your car's screen

Cabinwright is an app store for Kia and Hyundai head units that run NEMESIS. You install it once, then add, update and remove everything else from the car's own screen. It is free and open source.

  • Free and open source
  • Every change can be undone
  • Built and tested on a 2023 Kia EV6
Get started Source on GitHub

What you can do

Everything below comes from the store. Most of it is a switch you can turn back off.

Edit Menu

Hide and reorder the icons in All Menus, the head unit's own included. Apps you add from the store show up there too.

Needs a one-time change to the head unit's launcher, done from a computer.

Tweaks

Small fixes, each with an on/off switch:

  • Automatic daylight saving time
  • Skip the start-up screen and go straight to the home screen

Tweak packs add more switches to the same app.

Wireless Android Auto and CarPlay

A tweak pack with four switches:

  • Connect your phone without a cable
  • Your phone's next turn in the instrument cluster and head-up display
  • Reconnect Android Auto when it gets stuck after the car's hotspot was used
  • Keep wireless projection working with Engineering Mode's ADB TCP on

ADB over Wi-Fi

A tweak pack that lets a computer on the car's Wi-Fi use ADB, Android's debugging connection. It stays in step with Engineering Mode's own ADB switch.

No password: see Safety.

Get started

  1. Install NEMESIS

    NEMESIS is a separate community project that lets the head unit install packages. Follow its instructions.

  2. Install the Cabinwright store

    Download cabinwright.store-<version>.zip from the store's release page. Install it with NEMESIS, from a USB stick, or over ADB with nemesis install --update <zip>.

  3. Get the rest from the store

    Open Cabinwright on the head unit and install Edit Menu, Tweaks and the tweak packs you want. The store installs what a package needs first, and shows in plain words what each one changes before you agree.

Using the older kia.* packages?

This project used to be called kia-store, kia-menu and kia-tweaks. The new packages install beside the old ones and take over their settings, without turning anything off. Moving from the kia.* packages has the steps.

Tested on one car so far: a 2023 Kia EV6 (US), Gen5W head unit, Android 4.4, firmware CVEV.USA.0000.V015.012.260507. The store and Edit Menu are ordinary apps. Anything that changes system files is offered only for the exact firmware it was tested on, so on other cars the store won't offer it.

Safety

Changing your head unit is at your own risk. Here is what Cabinwright changes, and how to put it back.

What it changes

The store installs apps and its own background helper. Nothing changes the head unit's system files until you turn on a tweak that says so, and the store tells you before installing anything that does.

Every system change checks the file is exactly the factory one, and keeps a copy of the original first.

How to undo it

Turn a tweak's switch off and the original files go back, byte for byte. Remove an app or a tweak pack in the store; removing a pack turns its tweaks off. Some changes show only after the head unit restarts.

If you can't reach the Tweaks app

There is a USB rescue that doesn't need the screen: a restore script on a NEMESIS USB stick puts back the factory SystemUI (what Skip start-up screen changes), and another puts back the factory launcher (what Edit Menu changes).

Scripts: systemui/restore-systemui.sh in tweaks, launcher/restore-launcher.sh in menu.

ADB over Wi-Fi has no password

Anyone who joins the car's Wi-Fi can control the head unit. The head unit's ADB can't ask for a key, so there is no way to limit it to your computer. Turn it on only while you need it.

Only install apps you trust

Today, any app installed through NEMESIS can get full control of the head unit. That is how NEMESIS works, not something the store can stop yet. Apps in the store are reviewed, and the list is signed so it can't be swapped on the way to your car.

For developers

Everything is on GitHub under cabinwright. Apps are Kotlin or Java compiled against Android 4.4 (API 19), built without Gradle and shrunk with R8. On-car scripts are shell for the head unit's mksh and toolbox.

The index

The store reads apps/index.json and index.json.sig, an RSA-3072 SHA256withRSA signature over its exact bytes, checked against pinned keys. A sequence that never goes down and an expires 90 days out stop old copies being replayed. Each version pins its package's size and SHA-256, and carries a review of what it installs.

To add an app, release a NEMESIS zip on GitHub and open a pull request with apps/<id>.json: see CONTRIBUTING.

Tweak packs

A tweak pack is any NEMESIS package with a tweaks/<id>/ folder: a tweak.conf plus shell scripts (run.sh, or enable.sh, disable.sh and status.sh). Its switches appear in the Tweaks app, and tweaksd runs them. Packs need no install hooks. The format and lifecycle are in the tweaks repo's DESIGN.md.

The app API

Add one intent filter and your app appears in All Menus:

<category android:name=
  "dev.cabinwright.category.ALL_MENUS" />

The optional UI library gives you CarPage (the head unit's look, day and night), SplitScreen and CarAudio (play through the car's speakers). api/tools/build-app.sh builds an app; lint.sh checks it. See the menu repo.

Plan, not built yet

The store as the platform (store 2.0)

Install one package, the store, and get everything else from it. Apps would run without root and ask the store's broker for what they need, with the driver's approval: permissions are listed at install, enforced at use, and can be switched off per app. Tweaks would move under the same rules: the tweak runner moves into the store, each tweak declares the exact files, settings and services it touches, and the runner keeps every backup. The design is in docs/platform.md.
