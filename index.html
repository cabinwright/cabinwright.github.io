Apps and small fixes for your car's screen

Cabinwright is an app store for Kia and Hyundai head units that run NEMESIS. You install it once, then add, update and remove everything else from the car's own screen. It is free and open source.

  • Free and open source
  • Every change can be undone
  • Built and tested on a 2023 Kia EV6

Get started

  1. Install NEMESIS

    A separate community project that lets the head unit install packages: its instructions.

  2. Install the Cabinwright store

    Download it from the release page and install it with NEMESIS.

  3. Get the rest from the store

    In the NEMESIS app, go to Packages, select Cabinwright and tap Launch.
