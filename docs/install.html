Install

1. Install NEMESIS

NEMESIS is a separate community project that lets the head unit install packages. Follow its instructions.

2. Install the Cabinwright store

Download cabinwright.store-v<version>.zip from the store's release page. Install it with NEMESIS from a USB stick, or over ADB:

adb push cabinwright.store-v<version>.zip /data/local/tmp/
adb shell nemesis install --update /data/local/tmp/cabinwright.store-v<version>.zip

3. Open the store

On the head unit, open the NEMESIS app, go to Packages, select Cabinwright and tap Launch.

From there, install Edit Menu, Tweaks and the tweak packs you want. The store installs what a package needs first, and shows in plain words what each one changes before you agree.

4. Optional: icons in All Menus

The head unit's All Menus screen only shows its own apps. Edit Menu's launcher change adds Cabinwright and the apps you install, and lets you hide and reorder every icon. It replaces a system app, so it is built from your own car's launcher on a computer and never downloaded. The steps are in the menu repo's README.

Until then, open apps from NEMESIS → Packages → Launch.

Moving from the older kia.* packages

This project used to be called kia-store, kia-menu and kia-tweaks. The new packages install beside the old ones and take over their settings, without turning anything off. Follow Moving from the kia.* packages.
