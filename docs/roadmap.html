Roadmap

Everything on this page is a plan, not built yet.

The store as the platform (store 2.0)

Install one package, the store, and get everything else from it.

  • Apps without root. Apps ask the store's broker for what they need, with the driver's approval. Permissions are listed at install, enforced at use, and can be switched off per app.
  • Tweaks under the same rules. The tweak runner moves into the store. Each tweak declares the exact files, settings and services it touches, and the runner keeps every backup.
  • The store writes the manifest. Packages from the index get a NEMESIS manifest generated by the store, so a package can't give itself more than was reviewed.

The design is in the store repo's docs/platform.md.
