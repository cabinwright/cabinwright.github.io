Docs

Cabinwright is an app store for Kia and Hyundai head units that run NEMESIS. These pages go into more detail than the home page.

For drivers

  • Install: NEMESIS, the store, opening it the first time, the All Menus icons, and moving from the older kia.* packages.
  • Safety and undo: what Cabinwright changes, how to put it back, and the USB rescue.

For developers

  • For developers: the repos, the signed index, tweak packs and the app API.
  • Roadmap: where the store is heading. Plans, not built yet.

Which cars

Tested on one car so far: a 2023 Kia EV6 (US), Gen5W head unit, Android 4.4, firmware CVEV.USA.0000.V015.012.260507. The store and Edit Menu are ordinary apps. Anything that changes system files is offered only for the exact firmware it was tested on, so on other cars the store won't offer it.
